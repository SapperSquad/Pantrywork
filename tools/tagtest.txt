# Pantrywork tag-membership checks. Run via: tools\rcon.ps1 -File tools\tagtest.txt
# Pattern: put an item in a chest, `execute if items` against a tag.
# "Test passed" = in tag; for the negative check, `unless` passing = correct.
forceload add 0 0
setblock 8 -60 8 minecraft:chest
# --- sanity: FD's own tagging visible ---
