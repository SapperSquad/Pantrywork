# Fabric cost-floor gate overlays, on any Fabric harness WITH a Croptopia build and FD
# Refabricated: fabric-server (1.21.1, Croptopia 4.2.4), fabric-server-12110 (1.21.10, Croptopia
# REFABRICATED - mod id croptopia-refabricated, the review CF-2 case), fabric-server-2612 and
# fabric-server-262 (Croptopia 4.3.1). Not for fabric-server-12111 (FD only: tagtest-fabric-fd.txt).
# Same shape as tagtest-neo26-gates.txt (review TV-3):
# - OPEN lines use `unless` with stone: an applied overlay defines its tag -> "Test passed"; an
#   overlay that did not apply answers "Unknown item tag", unannotated, so a FAILURE.
# - CLOSED lines use `if` and carry `# expect: Unknown item tag`; a leaked overlay answers
#   "Test failed", a counted failure.
#
# 0.8.0 re-cut: 5 overlays became 14 and three of the old tag ids were renamed (the salts gate
# gained cookscollection, the vegetables gate gained kaleidoscope_cookery, the flour gate gained
# kaleidoscope_cookery). FIVE overlays are open on these harnesses, because FD Refabricated's
# mod id is literally `farmersdelight`, so the two new Farmer's-Delight-rescued gates open here
# as well as the three Croptopia ones:
#   OPEN   _4 cookscollection|croptopia      c:salts (its member, Pam's salt, is not installed)
#          _6 croptopia                      c:cheeses + c:milks
#          _7 croptopia|kaleidoscope_cookery c:vegetables
#          _10 farmersdelight                bridged/foods_raw_chicken (member F&C's chicken_parts
#                                            is not installed)
#          _11 farmersdelight|rusticdelight  bridged/raw_fishes (member KC's sashimi likewise)
#   CLOSED _1, _2, _3 (two tags), _5, _8, _9, _12, _13, _14
# Run:      tools\rcon.ps1 -File tools\tagtest-fabric-gates.txt > fabric-gates.out
# Classify: powershell -File tools\CountSuite.ps1 -Suite tools\tagtest-fabric-gates.txt -Output fabric-gates.out
# Expected: 22 passed, 0 failed, 10 expected.
